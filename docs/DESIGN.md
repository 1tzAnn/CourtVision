# Courtvision visual direction

Updated October 28, 2026.

Courtvision is a basketball notebook: warm paper, dark ink, burnt orange and navy comparisons. The product name is Courtvision, without an AI badge. Keep existing filenames for compatibility with saved local links.

Use system sans-serif for controls and body text, Georgia for page headings and headline figures. All fonts work offline. Body text is 15px; supporting copy should normally be 12–14px. Use plain section names and useful descriptions rather than slogans or claims of intelligence.

Palette: paper #f5f3ed, panel #fffefb, ink #252b2c, secondary ink #626863, accent #a64327, comparison #285e78. Main text, secondary text and primary button colors exceed 4.5:1 against their intended backgrounds. Charts use the same orange/navy pairing, with visible legends.

Preserve real data, model explanations, uncertainty and coverage limitations. Simplifying the presentation must not remove the evidence or turn associations into causal claims.

All eight pages were checked at desktop and 390px mobile widths, with no document-level horizontal overflow at the mobile breakpoint. Data tables may scroll within their own containers.

## Revised direction: calmer surfaces and a guided start

The later October 28 revision replaces the bright paper surfaces with muted sage (#d9ddd7 page, #e9ebe4 panels) and deep green (#243d36 sidebar, #28463b start panel). The main start action uses warm peach (#e9b28a) with dark green text. The original palette above documents the earlier version, not the current surface colors.

Home now asks for two teams and offers three connected actions: matchup, series, scouting. Teams carry into the chosen analysis, and same-team actions are disabled with an inline explanation. Player, lineup and shot exploration remain available below. Large data-count and model-score cards were removed from home; detailed model evaluation remains under About the data.

Each analysis route has an optional quick guide covering the workflow and relevant terms. Keep advanced analytics accessible without requiring a first-time visitor to understand every metric before starting.
